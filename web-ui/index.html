Схема системы

CosmoScan — микросервисы за API Gateway. Портал отправляет запросы на Gateway; сервисы обмениваются данными во внутренней сети.

Подключение к API

Запросы с форм ниже отправляются на API Gateway (см. схему выше).

Адрес единой точки входа. По умолчанию — порт 8090. Меняйте только при нестандартном развёртывании.

Документация API (Swagger UI)

Интерактивная OpenAPI-документация каждого микросервиса, проксируется через Gateway.

submission-service POST /works — приём работ Сценарий сдачи работы студентом, модель WorkResponse. file-storing-service POST/GET /files Загрузка и скачивание файлов (pdf, docx, txt, до 1 MiB). analysis-service GET /works/{id}/reports, /word-cloud Техотчёты и данные для облака слов.

Health check (Spring Actuator)

Прямые ссылки на /actuator/health backend-сервисов. Gateway Actuator не использует.

submission-service http://localhost:8091/actuator/health Откроется в новой вкладке — JSON Actuator. file-storing-service http://localhost:8092/actuator/health Откроется в новой вкладке — JSON Actuator. analysis-service http://localhost:8093/actuator/health Откроется в новой вкладке — JSON Actuator.

UC-1 Сдать работу

Студент загружает файл и сразу получает результат техпроверки. Соответствует POST /works.

Обязательный текстовый параметр studentFullName в multipart-запросе. Отображается в метаданных работы и передаётся в analysis-service.
Параметр file. Допустимые форматы: PDF, DOCX, TXT. Максимальный размер — 1 MiB. ZIP и другие типы отклоняются с 400.
Отправляет форму на Gateway. При успехе (201) в ответе — id работы, fileId и блок technicalReport (статус ACCEPTED или NEEDS_REVISION и список замечаний).

Покрытие тестами (JaCoCo)

      
HTML-отчёты JaCoCo (порог ≥ 60%). Ссылки ведут на http://localhost:8094 — нужен запущенный web-ui (docker compose up -d --build web-ui).

      

        
          submission-service
          http://localhost:8094/reports/submission/index.html

          http://localhost:8094/reports/files/index.html
          Хранение файлов, валидация формата и размера.

          http://localhost:8094/reports/analysis/index.html
          Техпроверка, word cloud, отчёты.
